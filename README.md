### [Weather & Outfit Suggester](weather-and-outfits/)

As repository name says it is a dynamic web application that automatically detects the user's location, fetches real-time weather data, and suggests a logical outfit combination (Outerwear + Top + Bottom) based on the temperature

* **Technologies:** HTML5, CSS3, Vanilla JavaScript (Classes, Async/Await, Fetch API), OpenWeatherMap API, GeoJS API.
* **Note:** This project focuses on clean architecture and using APIs. I didn't focused much in designing, i can add sum

| Status | Description |
| :--- | :--- |
| **Responsiveness** | **Fully responsive design using CSS Grid. Optimized for mobile and desktop screens.** |
| **Features** | **Location detection (IP-based), real-time temperature fetching, and a algorithm that filters clothe objects based on thermal properties.** |

(See the live site [here](https://m6min.github.io/web-playground/weather-and-outfits/))

### [Terminal Portfolio](terminal-theme-portfolio/)

This folder holds the source code for a example of personal website, designed to look minimalist and feel like a developer's command-line interface. My goal was to create an interactive experience using pure JavaScript logic and CSS layouts, avoiding any frameworks


* **Technologies:** HTML5, CSS3, Vanilla JavaScript
* **Note:** I wanted to use event listeners and dom manipulation in javascript.

| Status | Description |
| :--- | :--- |
| **Responsiveness** | **Works good on big or small screens without problem.** |
| **Features** | **Supports commands like `help`, `about`, `projects`.** |

(See the live site [here](https://m6min.github.io/web-playground/terminal-theme-portfolio/)) 
---

## 🚀 Getting Started

To run this project on your local machine, follow these steps:

1.  Clone the repository:
    ```bash
    git clone [https://github.com/m6min/web-playground/terminal-theme-portfolio.git](https://github.com/m6min/web-playground/terminal-theme-portfolio.git)
    ```

2.  Navigate to the project folder.
3.  Open the `index.html` file directly in your browser.
